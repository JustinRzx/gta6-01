A top-down open-world crime game on a plain `<canvas>`: walk the pavements or steal and drive cars through a seeded street grid, run missions for money, fight, and outrun the police as the wanted stars climb and patrol cruisers with flashing light bars chase you down. Every sprite, tile and song is processed from the raw art under `raw/` and served as a static file with no build step and no network request.

## Run it

```sh
node serve.ts --port 8080
# then open http://localhost:8080 in desktop Chrome
```
