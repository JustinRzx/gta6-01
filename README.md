A top-down open-world crime game drawn on a single canvas from static files. Drive and steal cars through a seeded city grid, evade wanted stars and chasing police, punch and shoot your way out, and run jobs across town — with a minimap, speedometer, health, saved progress and a looping soundtrack. No build step, no library, no network request: every script, image, sound and font lives under `game/`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in Chrome
```
