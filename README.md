Sunset City is a top-down open-world crime game that runs in a single `<canvas>` from static files only. Walk the streets with WASD, get into cars with E and drive them, weave through traffic, and take delivery jobs from the gold marker. Steal cars, hit pedestrians or ram the police and a wanted level kicks in — cruisers with flashing lights will chase you until you shake them, while the chase music takes over from the calm city loop.

## Run it

```sh
node serve.ts    # serves game/ on http://localhost:8080 — open that in a browser
```
